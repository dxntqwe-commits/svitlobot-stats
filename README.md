# Svitlobot Stats — Railway Worker

Telegram-бот про світло та повітряну тривогу в Києві.

## Що вміє

- 💡 Показує, скільки датчиків [Світлобота](https://svitlobot.in.ua) у Києві зараз зі світлом, і **називає райони, де гірше за все** (топ-5 — і в тексті, і на картинці).
- ⚖️ Враховує, що в районах різна кількість датчиків: рейтинг згладжується, райони з малою вибіркою позначаються `⚠️`, а райони з менш ніж 5 точок не потрапляють у рейтинг.
- 📊 Щодня о 12:05 порівнює світло з учорашнім (о цей самий час).
- 🚨 Повідомляє про початок, зміну рівня та відбій повітряної тривоги в Києві.
- 🎯 Під час тривоги кожні 10 хв **редагує той самий пост**: цілі навколо Києва, відстань, сторона світу, курс (наскільки це дає джерело).
- 📌 Закріплює пост про останню тривогу. Коли починається нова — старий пост відкріплюється й видаляється.
- 🔕 Усі повідомлення надсилає **без сповіщень**.

## Команди

| Команда | Що робить |
|---|---|
| `/svitlo` | Світло по місту: діаграма + топ-5 районів |
| `/rayony` | Світло по всіх районах |
| `/tryvoga` | Статус тривоги + цілі поруч (також працюють `/trivoga` і `/trevoga`) |
| `/dopomoga` | Довідка |
| `/vidnovyty` | Для адмінів: відновити вчорашній замір (відповіддю на пост бота о 12:05) |

Автоматично: статистика світла о 00:05, 04:05, 08:05, 12:05, 16:05, 20:05 (за Києвом); тривога перевіряється кожні 40 с.

## Railway

**Змінні середовища** (Variables):

| Змінна | Обов'язкова | Опис |
|---|---|---|
| `TELEGRAM_TOKEN` | так | токен від BotFather |
| `TELEGRAM_CHAT_ID` | так | ID чату або каналу |
| `ADMIN_IDS` | ні | ID адмінів через кому — для `/vidnovyty` |
| `MIN_DISTRICT_POINTS` | ні | мін. точок для рейтингу району (за замовчуванням 5) |
| `RANK_SMOOTHING` | ні | сила згладжування рейтингу (за замовчуванням 10) |
| `ALERT_REFRESH_MIN` | ні | як часто оновлювати цілі, хв (за замовчуванням 10) |

**Права бота в чаті:** адміністратор з правами *Закріплювати повідомлення* та *Видаляти повідомлення* (без цього пін і прибирання старого поста не працюватимуть).

**Запуск:** один Service, Procfile `worker: python bot.py`, Replicas = 1. Не запускай локально ту саму копію з тим самим токеном (буде `409 Conflict`).

**Без Volume.** Бот не потребує бази даних. Стан лежить у `data/state.json` і на безкоштовному плані скидається при деплої/перезапуску. Бот відновлюється сам:
- пост про тривогу — знаходить у закріпі чату (він перевіряє, що закріплене повідомлення належить йому);
- порівняння з учора — командою `/vidnovyty` у відповідь на вчорашній пост о 12:05 (бот прочитає цифри з підпису).

## Райони

За замовчуванням район визначається за найближчим із 10 наближених центрів — межі між районами приблизні. Для точності поклади `data/districts.geojson` з реальними межами (Polygon/MultiPolygon, назви в `name:uk` або `name`) — бот підхопить його сам.

## Дані

Це вибірка датчиків Світлобота, а не всіх киян: відсоток показує частку **датчиків** зі світлом.
