# Svitlobot Stats — Railway Worker

Telegram-бот для статистики електропостачання Києва та статусу повітряної тривоги.

## Команди

- `/svitlo` — отримати графік і поточну статистику світла.
- `/trivoga` — перевірити статус повітряної тривоги в Києві.

Автоматично:
- перевіряє статус тривоги кожні 40 секунд;
- надсилає статистику світла о 00:05, 04:05, 08:05, 12:05, 16:05 та 20:05 за київським часом.

## Railway: змінні середовища

У сервісі відкрий **Variables** та додай:

- `TELEGRAM_TOKEN` — новий токен бота від BotFather;
- `TELEGRAM_CHAT_ID` — ID чату або каналу, куди бот надсилає автоматичні повідомлення.

Не додавай токен у файли GitHub і не надсилай його в чатах чи скриншотах.

## Railway: запуск

1. Підключи цей репозиторій до одного Railway Service.
2. Переконайся, що сервіс запускається як Worker через Procfile: `worker: python bot.py`.
3. Встанови **Replicas = 1**, якщо така настройка доступна.
4. Не запускай той самий бот локально, поки він працює на Railway.
5. Переконайся, що в інших Railway-сервісах/проєктах немає процесу з тим самим токеном.
6. Зроби один Deploy і дочекайся `Application started` без помилки 409.

## Збереження стану між перезапусками

За замовчуванням файл стану створюється в `data/state.json`. Для збереження між деплоями додай Railway Volume і змонтуй його в `/app/data`. Можна також задати змінну `STATE_FILE` з іншим шляхом усередині Volume.

Без Volume бот працюватиме, але після перезапуску може втратити ID попереднього повідомлення. Перший запуск без збереженого стану синхронізує поточний статус тривоги без надсилання фальшивого повідомлення про її початок.

## Важливо про 409 Conflict

`409 Conflict: terminated by other getUpdates request` означає, що з тим самим токеном одночасно працює інший процес polling. Повторний деплой сам по собі не усуває інший процес. Зупини всі інші копії, залиш одну репліку та один активний Worker.

## Локальний запуск для тесту

Створи віртуальне середовище, встанови залежності з `requirements.txt`, задай `TELEGRAM_TOKEN` і `TELEGRAM_CHAT_ID`, потім виконай `python bot.py`. Не запускай локальну копію одночасно з Railway.


## Виправлення парсингу Svitlobot

API віддає плоскі поля, розділені `;&&&;`. Скрипт групує їх по 11 полів, читає назву об'єкта з поля 3, а статус — з поля 8. Для графіка "Стан світла в Києві" враховуються записи, назва яких починається з "Київ". Статус `0` не входить до трьох категорій графіка.
